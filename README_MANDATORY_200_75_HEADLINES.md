# Mandatory 200-Year + 75-Year Headlines

The previous source expansion did NOT make these two cards mandatory.
This build does.

PUBLICATION CONTRACT
A complete edition cannot be marked published unless both y200 and y76
(the internal compatibility key for the approved 75-years-ago window) have:
- exact historical issue date
- real title
- identifiable publication
- valid HTTP(S) source URL

RECOVERY
Missing side headlines get two dedicated searches:
1. National / papers-of-record / major-newspaper / institutional search.
2. Broad credible same-date fallback across university, state, historical,
   regional and other institutional collections.

If no national lead can be verified, the fallback selects the strongest
consequential credible American newspaper story from the exact date.
It never fabricates a story.

    Fill 200/75 Headlines

Use that button to populate the current edition WITHOUT rerunning all 19 agents.

FUTURE SITE
